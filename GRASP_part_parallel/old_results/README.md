# Stari (istorijski) rezultati

Ovaj folder sadrži izveštaje iz ranijih faza razvoja algoritma (pre finalnih
optimizacija opisanih u `IMPROVEMENT.md` i u radu), sačuvane radi poređenja
tokom razvoja. **Nisu finalni rezultati** i nisu korišćeni u tabelama u
seminarskom radu.

Finalni rezultati, korišćeni u radu, nalaze se u `../reports/`.
